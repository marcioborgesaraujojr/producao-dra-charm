Detectar conversa travada
Cliente repetindo a mesma mensagem três vezes é sinal de que não está sendo entendido (ou tem outro robô do outro lado). Em vez de rodar em círculo, passa pra humano.
Marcar como lida no WhatsApp do cliente
O tiquinho azul aparece pra ele assim que o robô lê. Sem isso a mensagem fica "não lida" mesmo já respondida.
Encerrar por inatividade
Cliente que some no meio da conversa não pode ficar ocupando a fila como se estivesse esperando resposta.
0 = nunca encerra. No Notificações o padrão é 30.
0 = sem espera. Serve pra cliente que acabou de falar com humano não cair de novo no robô.
Deixe vazio pra encerrar calado, sem mandar nada pro cliente.
Como o encerramento funciona aqui: uma rotina roda de 10 em 10 minutos, procura conversa em modo robô parada há mais tempo que o limite, manda a mensagem (se tiver uma) e devolve a conversa pro estado normal. Conversa que já tem atendente não é tocada.

Onde vai o dinheiro
Saldo não aparece aqui de propósito. A Anthropic não publica o saldo por API — só dentro do Console dela. Este painel mostra o gasto; o saldo e a recarga automática ficam em console.anthropic.com → Settings → Billing. Quando o crédito acaba a API para de responder, e aí toda conversa cai direto pra fila humana.
